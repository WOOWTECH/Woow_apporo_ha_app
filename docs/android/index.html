Apporo aiot

OAuth client_id endpoint for the Apporo aiot Android companion app.

  • Release build (com.apporo.aiot): apporoaiot://auth-callback
  • Debug build (com.apporo.aiot.debug): apporoaiot-dev://auth-callback

The app intercepts the callback inside its own sign-in web view, so these schemes need no auth-callback intent filter in the manifests.
